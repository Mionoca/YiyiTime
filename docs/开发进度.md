### M1 用户与绑定

云函数 action：

- [x] `user.get`：返回 `{user:{openid,nickname,avatarFileID,profileComplete,coupleId}}`。
- [x] `user.updateProfile`：昵称 1–12 字、头像 `cloud://` 前缀校验；两字段都空返回 `PROFILE_REQUIRED`。
- [x] `bind.create`：选开始日期（2000-01-01 至今天）生成 6 位数字邀请码，24 小时有效；同一用户同时只有一个活跃邀请，可 `regenerate` 换码；已绑定返回 `ALREADY_BOUND`。
- [x] `bind.preview`：返回邀请人昵称/头像、开始日期、有效期，不返回 `openid`，不占用邀请码。
- [x] `bind.apply`：事务内置为 `applied`，防止双方同时申请；已申请过返回 `BIND_ALREADY_APPLIED`。
- [x] `bind.confirm`：仅邀请人可确认；事务内创建 `couples`、回写双方 `coupleId`、邀请置 `confirmed`；已确认时幂等返回已有关系。
- [x] `bind.cancel`：邀请人/申请人均可取消进行中的邀请；已绑定不可取消。
- [x] `bind.status`：`unbound / code_created / applied_by_partner / applied_by_me / bound` 状态机，过期邀请惰性置 `expired`。
- [x] 绑定失败限流：1 小时窗口内连续失败 5 次后 `preview/apply` 返回 `BIND_RATE_LIMITED`；成功后清零。
- [x] `home.get`（已绑定部分）：`couple`（开始日期、第几天、下一个纪念日）、`partner` 资料、`bind.state`；`lastActiveAt` 5 分钟节流更新；couples 文档缺失时记日志并重置 `coupleId` 按未绑定返回。

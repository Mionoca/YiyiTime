**并发与一致性边界**

| 事项 | 现状 | 计划 |
| --- | --- | --- |
| 绑定失败限流并发突发可能超过 5 次 / 小时 | 计数用 `inc` 不丢，但预检与自增不是事务，同一瞬间并发都能过 | 两人场景无法触发；要严格可改事务预留 |
| `wish.add` 的 100 条上限是 check-then-write | 先计数再写，极端并发可能短暂超限 | 后续改事务内计数 |
| 纪念日 8 条上限同样是 check-then-write（M12） | 两台设备同时提交可能多出 1 条 | 同上 |
| `bind.apply` 事务内邀请文档缺失未兜底 | `bind_invites` 从不删除，正常路径不可达 | 概率极低；要兜底可捕获后转 `INVITE_USED` |
| `bind.confirm` 并发双提交的第二个请求 | 事务内看到 `confirmed` 报 `INVITE_USED`，不是幂等返回 | 单端按钮有防重，可接受 |

| 成员列表不是恰好两人时 `mood.list` 只返回自己 | 控制台手工换绑可能残留 3 个 openid，服务端不猜「谁是现任」 | 正常绑定恒为 2 人；产品化解绑应走 `couples.status` 流转 |

## 四、怎么跑起来 / 自检

```bash
cd D:/大学/YiyiTime
node --test tests/*.test.js      # 期望 769 pass / 0 fail
node scripts/release-check.js    # 期望 21 PASS + 8 TODO + 0 FAIL（脏工作区多 1 WARN）
node scripts/check-secrets.js    # 期望 exit 0
```

看单个模块：`node --test tests/growth.test.js tests/client-growth.test.js`。

**本机坑（都踩过）**

- `node --test tests/` 在 Node 22 会把目录当模块，报 `Cannot find module`——必须写 `tests/*.test.js`。
- `release-check` / `check-secrets` 依赖 git：受限沙箱里「两个文件未被跟踪」两项降级成 `[TODO]`，`check-secrets` 的 CLI 用例会 `skip`，这不等于失败。
- `scripts/release-check.js` 与 `cloudfunctions/api/handlers/home.js` 是 **CRLF**，其余文档/测试是 LF——批量替换要用 Python 按文件判断换行符，否则多行锚点匹配不到。
- `project.private.config.json`（已 gitignore）里的 `libVersion` 会**覆盖** `project.config.json`，开发者工具实际按 private 的值跑。
- 临时目录统一用 `D:/_yiyi_xxx`。

## 五、改动约定（沿用，别破坏）

1. **文档先行**：先改 `docs/技术设计文档.md`（5.3 字段表 / 7.x 契约 / 8.x 页面 / 16.2–16.4 表），再写代码，最后靠 `tests/contract.test.js` 把两边锁死。表和代码必须在同一个提交里落地，否则契约测试会红。
2. **每完成一个阶段**：全量 `node --test` + `release-check` + `check-secrets` 全绿 → 独立只读审查（只读不改仓）→ 修 P0/P1 → `git push origin hjj` → 更新本文与 README 的用例数。
3. **部署顺序**：新增集合先在控制台建 → 部署云函数 → 上传小程序端。反了会报「这个操作还不存在」。只改客户端样式的轮次不用重部署云函数，但小程序端要重传。
4. **安全红线**：客户端只能走 `utils/api.js`；不信任客户端传的 `openid` / `coupleId` / 日期；双人 handler 先 `ctx.requireBound()` 再碰伴侣数据；日志不打正文、不打完整邀请码、openid / coupleId 只留 6 位。
5. **视觉规则**（8.7）：3rpx 虚线描边 + 4/6rpx 小圆角 + 彩色硬阴影、150ms linear、`:active` 位移 3rpx；禁渐变、禁 999rpx 胶囊、不引网络字体；正文只用 `--ink` / `--muted`。
6. **导航**：`home` / `ledger` / `profile` 是 tab 页（`wx.switchTab` + `TAB_ROUTES` 判断 + `onShow` 首行 `tabbar.sync`）；其余页面一律 `wx.navigateTo`。
7. **提交**：commit 信息写入 `.git/yiyi-commit-rNN.txt` 后 `git commit -F`；push 前设 `HTTPS_PROXY=http://127.0.0.1:7890`；push 后核对 `git rev-parse HEAD` 与 `git ls-remote origin hjj` 一致、工作区干净。
